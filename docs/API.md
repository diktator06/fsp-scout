# API «Скаута»

> Документ собирается командой `make openapi` из [openapi.json](openapi.json) — той же спецификации, что отдаёт Swagger UI на стенде (`/api/docs`). Правка вручную будет перезаписана.

Скаут API 0.1.0: 126 методов в 21 группах, OpenAPI 3.1.0. Базовый путь — `/api/v1`, формат — JSON в UTF-8.

## Вход и роли

- `POST /api/v1/auth/login` возвращает access-токен (JWT, 15 минут) и ставит refresh-токен в httpOnly-cookie с путём `/api/v1/auth`. Access-токен передаётся в заголовке `Authorization: Bearer <token>`; `POST /api/v1/auth/refresh` выдаёт новый и ротирует cookie, повтор старого refresh-токена отзывает всю цепочку.
- Claims access-токена совместимы с Keycloak: роль — в `realm_access.roles` (`candidate`, `employer`, `methodist`). Метод чужой роли отвечает 403.
- Вход через ФСП ID — `POST /api/v1/auth/fsp/start` и `/auth/fsp/callback` (OIDC Authorization Code + PKCE), подробнее — [FSP_INTEGRATION.md](FSP_INTEGRATION.md).
- Вход, регистрация, выгрузка и песочница ATS ограничены по частоте: 429 с `details.retry_after_seconds`.

## Ошибки

Все ошибки — в едином формате; по `code` клиент выбирает реакцию, `message` можно показывать пользователю, `details` уточняет поле или лимит.

```json
{"error": {"code": "email_already_registered", "message": "Пользователь с таким email уже зарегистрирован", "details": {}}}
```

| Статус | Когда |
|---|---|
| 400 | Некорректный запрос, например чужой или просроченный `state` ФСП ID |
| 401 | Нет токена или он недействителен |
| 403 | Роль не та или действие запрещено уровнем доверия компании |
| 404 | Объект не найден или принадлежит другому пользователю |
| 409 | Конфликт с состоянием: повторное приглашение, ФСП ID уже привязан и т. п. |
| 422 | Ошибка валидации; `details` содержит поля |
| 429 | Превышен лимит запросов |
| 503 | Недоступен внешний сервис (ФСП ID, реестр) |
