# Скаут

Платформа подбора ИТ-специалистов с **обратной механикой** и верифицированным профилем участника
Федерации спортивного программирования (ФСП). Работодатель сам находит кандидата в базе, где
специалисты разложены по категориям, и приглашает его с обязательной вилкой зарплаты. Категорию
кандидату присваивает не резюме, а опрос и адаптивный тест.

Спецтрек ФСП, «Лидеры цифровой трансформации 2026». Архитектура и план — в
[ARCHITECTURE_AND_PLAN.md](ARCHITECTURE_AND_PLAN.md).

## Быстрый старт

Нужен только Docker (Compose v2). Интернет нужен только для сборки образов, сам стенд работает
полностью офлайн.

```bash
docker compose up --build
```

| Что | Адрес |
|---|---|
| Приложение | http://localhost:8080 |
| Swagger UI (работает без интернета) | http://localhost:8080/api/docs |
| OpenAPI-спецификация | http://localhost:8080/api/openapi.json |
| Mailpit — письма подтверждения email | http://localhost:8025 |

При старте бэкенд сам применяет миграции и наполняет справочники: 7 специализаций, 4 грейда,
28 категорий, 152 навыка с алиасами и 12 отраслей. Файл `.env` не обязателен: все значения по
умолчанию заданы в `docker-compose.yml`, а для переопределения есть шаблон
[.env.example](.env.example).

### Демо-аккаунты

Тестовые учётные записи локального стенда, пароль у всех `ScoutDemo2026`. На странице входа их
можно подставить одной кнопкой.

| Роль | Email |
|---|---|
| Специалист | `candidate@example.com` |
| Работодатель | `employer@example.com` |
| Методист | `methodist@example.com` |

Чтобы проверить регистрацию с нуля: зарегистрируйтесь на http://localhost:8080/auth/register,
откройте письмо в Mailpit и перейдите по ссылке — аккаунт подтвердится, и откроется кабинет.

## Что уже работает

- Регистрация специалиста или работодателя с обязательным согласием на обработку ПДн и
  подтверждением email. Пока email не подтверждён, войти нельзя.
- Вход, access-JWT (claims совместимы с Keycloak) и ротация refresh-токена в httpOnly-cookie.
  При повторном использовании отозванного токена отзывается вся цепочка сессий.
- Ролевой доступ `candidate` / `employer` / `methodist` на API и на маршрутах фронтенда.
- Справочники: специализации, грейды, категории, отрасли, навыки с поиском по алиасам
  («питон» → Python). Изменение справочников доступно только методисту.
- Фронтенд: лендинг, вход и регистрация, кабинеты трёх ролей, дизайн-система
  (`/design-system`) с универсальными виджетами — бейдж категории, вилка зарплаты, индекс
  подтверждённого профиля, таймлайн статусов приглашения.

## Локальная разработка

Нужны Python 3.13 с [uv](https://docs.astral.sh/uv/), Node.js 22.22+ и Docker для PostgreSQL.

```bash
make install        # зависимости бэкенда (uv) и фронтенда (npm)
make dev-backend    # PostgreSQL и Mailpit в Docker, API с автоперезагрузкой на :8000
make dev-frontend   # Vite на :5173, /api проксируется на :8000
```

Все команды перечислены в `make help`. Основные:

| Команда | Что делает |
|---|---|
| `make test` | тесты бэкенда (pytest на реальном PostgreSQL) и фронтенда (vitest) |
| `make lint` | ruff, mypy в строгом режиме, eslint, tsc и проверка правил комментариев |
| `make openapi` | выгрузка `docs/openapi.json` и перегенерация TS-типов клиента |
| `make revision m="…"` | новая миграция Alembic |
| `make reset` | остановка стенда с удалением данных БД |

Тесты бэкенда создают отдельную базу `fsp_scout_test`, применяют к ней миграции с нуля и
изолируют каждый тест транзакцией.

## Структура

```
backend/            FastAPI: api → services → crud → models, schemas, core, Alembic, тесты
frontend/           React 19 + Vite + Mantine: app, api, features, layouts, pages, shared/ui
docs/               OpenAPI и сопроводительная документация
tools/              проверка правил кода (docstring и комментарии на русском, только внутри функций)
docker-compose.yml  db (PostgreSQL 16 + pgvector), backend, frontend (nginx), mailpit
```

Подробное дерево и роль каждого модуля — в §4
[плана архитектуры](ARCHITECTURE_AND_PLAN.md).
